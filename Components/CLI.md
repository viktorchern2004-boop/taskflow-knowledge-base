# CLI – інтерфейс командного рядка

**Запланований файл:** src/taskflow/cli.py.

Приймає команди та параметри користувача і передає їх у [[TaskService]]. Не повинен самостійно змінювати [[JsonStorage]].

| Команда | Призначення |
| --- | --- |
| add | додавання [[Task]] |
| list | перегляд та фільтри за [[TaskStatus]] / [[TaskPriority]] |
| show ID | показати завдання |
| update ID | змінити завдання |
| delete ID | видалити з підтвердженням |

Вимоги: зрозумілі помилки при неправильних аргументах, відсутніх ID та пошкодженому сховищі. Узгоджені терміни описані в [[Glossary]].
