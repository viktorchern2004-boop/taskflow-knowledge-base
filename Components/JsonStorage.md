# JsonStorage – сховище JSON

**Запланований файл:** src/taskflow/storage.py.

Зберігає [[Task]] у локальному JSON-файлі без зовнішнього сервера. Вибір обґрунтований у [[ADR-001-Local-JSON]].

## Вимоги
1. Відсутній файл обробляється коректно.
2. JSON читається зі структурною перевіркою.
3. Запис по можливості здійснюється через тимчасовий файл та атомарну заміну.
4. Пошкоджений JSON не перезаписується мовчки.
5. Користувацькі дані виключаються з Git.

Використовується [[TaskService]], а поля регламентує [[TaskModel]].
