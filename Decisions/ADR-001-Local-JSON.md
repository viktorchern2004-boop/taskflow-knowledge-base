# ADR-001 – Локальне JSON-сховище

**Статус:** accepted.

## Контекст
TaskFlow CLI – однокористувацький локальний застосунок для [[Task]], що має працювати без мережі.

## Рішення
Використовувати локальний JSON-файл та компонент [[JsonStorage]]. Структуру записів перевіряє [[TaskModel]], а запити координує [[TaskService]].

## Альтернативи
- SQLite: кращі транзакції, але зайва складність для початкового навчального етапу.
- Віддалена СУБД: підтримка багатьох користувачів, але потрібна зовнішня інфраструктура.

## Наслідки
Плюси: простота, відтворюваність і прозорість формату. Мінуси: обмеження масштабування та паралельного запису. Додаток повинен зберігати завдання після перезапуску.
