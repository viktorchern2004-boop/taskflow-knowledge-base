# TaskStatus – статус завдання

Статус описує стан виконання [[Task]].

| Значення | Значення для користувача |
| --- | --- |
| todo | ще не розпочато |
| in_progress | робота виконується |
| done | завершено |

Початкове значення – todo. Невідомий статус має викликати помилку валідації, не змінюючи збережених даних. Валідацію визначає [[TaskModel]], оновлення виконує [[TaskService]], а команду вводять через [[CLI]].
